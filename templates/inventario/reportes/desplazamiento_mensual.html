Desplazamiento mensual

Sube el Excel del programa mensual (hojas Resumen / Datos) e indícanos el mes y año de consulta. El sistema lo complementa con los surtimientos reales de ese periodo y genera el archivo listo para directivos.

Generar reporte complementado
{% csrf_token %}
Debe incluir la hoja Datos / DATOS con columnas CLUES, CLAVE y cantidad entregada. Sirve formato hospitalario o 1er nivel.
Qué hace el proceso
  1. Lee el programa mensual (hoja Datos).
  2. Consulta surtimientos del mes/año solo para las CLUES del archivo (agregado en BD).
  3. Cruza por CLUES + CLAVE y llena la cantidad entregada.
  4. Agrega en la misma hoja las entregas adicionales no listadas en el programa.
  5. Actualiza el Resumen con indicadores para directivos.

Acepta el formato hospitalario (hoja Datos) y el de 1er nivel (hojas DATOS / RESUMEN). Si el proceso es muy grande (>8 000 líneas), solo se colorean las filas con entrega para evitar timeout. Si el proceso tarda mucho o regresa error 502, prueba con un Excel más liviano (una entidad) o un mes con menos movimiento. Límite de archivo: 15 MB.

Leyenda en Datos

  • Amarillo Entrega parcial
  • Azul Sin entrega por existencia/disponibilidad
  • Naranja Entrega adicional
